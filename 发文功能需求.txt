本文涉及的所有指令都要有一个前缀触发，比如`》`

写发文新插件

发文格式有三行
```
标题-难度+分数
正文（不含空白字符）
-----第xxxxx段-共xx字-@触发人（以文本的形式，有群昵称用群昵称，没有用昵称，再没有用QQ号）
```

如：
```
中秋节想你的心情-水0.11
求你来爱我，看了无数次你分享的那篇《分手后还能重来吗》？到现在我都不懂，有些文章都是作者刻画的，并不是所有的事都是绝对的，我也一直在等着你的消息，可是一次又一次的失望到最后将会变成绝望，到那时我恐怕就再也没有勇气去爱你了。
-----第47884段-共111字-@聆竹听风
```

可能是要写一个函数来发文，输入为正文，标题（可选，若不给则没有标题只有难度），段号（文本，可选，若不给则随机段号10001-99998），触发人（文本），输出为发文的消息内容，难度用已有的函数计算。

接下来要想办法收集语料，可以上极速中文网搜集一些语料。存在某文件夹下。（在服务器上操作，要考虑磁盘空间的问题）

还要支持管理员（群聊私聊都可）上传文章/书(txt格式)。上传内容的编码要进行处理，最终要以utf-8的格式存储，删除所有空白字符。支持管理员（群聊私聊都可）对指定文章内容进行正则替换。文件名即为标题。上传文章/书时，要输入标题。标题已有，则更新内容，标题没有，则新建内容。还支持删除文章。

总之就是要有一套管理文章的指令。

所有用户都能查询所有的文章标题。

上传的文章也存在某文件夹下。

指定文件夹下都是utf-8 txt格式存储，文件名都是 标题.txt 的形式。文章标题不允许包含空白字符、路径分隔符或控制字符。

接下来要有发文指令


第一类发文（文章/小说）：

    有选择文章功能。

    设置每段字数（要有限制）

    顺序发文/随机段落发文/全局随机选字发文。

    “全局随机选字”按字符下标抽样，不要求字符内容互不相同；同一个下标不能重复抽取。
    可指定下标范围，例如 `》乱 200 文章标题 1000-5000`，范围从 1 开始且包含起止位置。
    
    顺序发文可保存记录进度（只按人保存，和群无关，每个文章的进度都要保存）可以操作进度（快进多少字，快退多少字，用户也要能看整个文章有多少字）。

    另外两种无需保存进度。

第二类发文（按难度发文）：

    选择难度

    设置每段字数（要有限制）

    保证发出的段落都是在某个难度等级内的。

    （可能需要事先对所有语料进行处理，要写成管理员可以用机器人进行处理的形式，这个你得结合难度计算的方法看看有没有高效的算法）


发文都用随机段号（但是要保证同一个session（群聊或者私聊）里短时间段号不重复）

还设置自动发下一段的功能，这涉及到成绩的读取

```
第45550段 速度166.73 击键6.59 码长2.37 键准82.15% 回改13 错字0 字数100 时间00:35.987 打词61.00% 选重5 静打跟打器v3.1.2
```

格式大致是这样的。

读取成绩是为了实现，指定条件才发下一段。比如速度>=多少，击键>=多少。
也可以不做限制，自动发下一段。

这边也要设计一套指令，如果没有设置那就无条件自动发。

但是自动的大前提一定是，触发发文的人，发出了该文段的成绩。（可能需要每个群里每个人维护一个session，若是私聊那就是对每个人维护一个session，这个session有1小时的超时时间）

有命令主动关闭session。


所有操作需要尽可能简单，能一次操作的就不要两次操作。（兼容一次消息和两次消息）
